## Gohan Lab - Productos Personalizados

**Nombre:** Florencia Devoto

## Descripción

Gohan Lab es un proyecto de ecommerce de productos personalizados.

En esta primera etapa se desarrolló la estructura general de la aplicación utilizando HTML.

El sitio cuenta con una página de inicio, páginas de categorías de productos, una página de inicio de sesión y una página de registro de usuarios.

Las categorías iniciales del proyecto son:

- Mates y accesorios
- Vasos
- Tablas y accesorios
- Otros personalizados
